# Package A — Clarisa's Brief (Full-Stack Growth Agency)

Source: `../instructions.md` + the 3 storyboard images at `../images/`.

## Positioning

Zuniga as a **full-stack growth studio** that builds websites end-to-end: design, development, SEO, hosting, automations, and backend. The hero is a cinematic 5-phase brand-genesis animation that ends on a fully-built example client site ("YOUR BUSINESS").

## Voice

- **Headline:** "BUILT TO GROW. DESIGNED TO CONVERT."
- **Subhead:** "Websites engineered to attract, convert, and scale your business."
- **CTA:** "Let's Build Your Site →"
- Confident, agency-default, conversion-forward. Never apologetic.

## Visual mood

- Apple product launch × Porsche reveal film × Linear.app
- Matte black + charcoal background
- Metallic dusty rose as the primary accent — feels brushed, expensive, *cool* (not warm pink)
- Rose-gold thin edge highlights
- Warm gold appears as luxury punctuation only (<10% of any frame)
- Soft cinematic easing — no bouncy, no snappy
- Slow shimmer on idle (every 20–30s)

## How to sync this package

From inside `01-clarisa-brief--package-a/`:

```
/design-sync
```

`/design-sync` reads every `*.html` file with a `@dsCard` first-line marker, builds the structural diff against the chosen Claude design project, and uploads only what changed.
